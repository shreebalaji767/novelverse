MANUAL GITHUB PUBLISHING

Publish your package

  1. Export your package JSON and keep a backup.
  2. Open the package and create the listed files inside your repository. Chapter files go under novels/<series-id>/chapters/.
  3. Merge the included novel entry into data/novels.json; merge character entries into data/characters.json and world entries into data/worlds.json.
  4. Commit the files to the main branch. GitHub Actions validates and deploys the website.
  5. Open Novels on the deployed site and check your published series.

The Studio does not have GitHub write access and cannot publish or deploy for you. Never paste passwords, access tokens or private credentials into this page.
